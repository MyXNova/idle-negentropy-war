# 熵減戰爭 (Entropy Reduction War)

> 對抗宇宙熵增的科幻放置遊戲

## 遊戲簡介

《熵減戰爭》是一款以“熵減”為核心主題的科幻放置類策略遊戲。你將領導文明，從微觀的原子排序、分子冷卻，到宏觀的恒星熄滅、黑洞解壓，最終實現能量物質化和宇宙單一化，對抗宇宙的熵增法則，追求最低熵的終極秩序。遊戲融合了資源管理、科技樹、建築系統、階段推進、成就系統、宇宙探索等多種玩法，兼具科幻世界觀與策略深度。

## 遊戲特色

- **熵減進程**：手動推進，從原子排序到宇宙單一化，體驗逐步逆轉熵增的成就感。
- **科技與建築**：解鎖並升級與熵減階段對應的科技和建築，提升資源產出與熵減效率。
- **資源管理**：能量、物質、暗物質、反物質、奈米材料、量子比特等多種資源協同發展。
- **宇宙探索系統**：消耗探測器派遣探索，抽取高方差資源池、稀有掉落，收集碎片/日誌合成稀有獎勵，體驗未知與收集樂趣。
- **畢業進度視覺化**：科技、階段、建築、熵減完成度四維度畢業進度一目了然，目標清晰。
- **黑暗森林法則**：座標暴露過高會觸發降維打擊，需謹慎發展。部分科技和建築可以降低暴露值或提供防護。
- **高自由度成長**：多線目標、分支結局、策略分配，支援多種成長與畢業路徑。
- **開發者友好**：內置 GM 面板，支持資源、建築、科技、階段等一鍵調整，便於測試與二創。

## 遊戲玩法

1. **手動熵減**：點擊“執行熵減”按鈕，消耗資源推進當前熵減階段。
2. **建造建築**：建造和升級當前階段的建築，提升資源產出和熵減效率。
3. **解鎖科技**：解鎖與當前階段相關的科技，獲得新能力和更高效率。
4. **宇宙探索**：製造探測器，派遣探索，抽取資源池與稀有掉落，收集碎片/日誌合成稀有獎勵。
5. **畢業進度追蹤**：畢業進度卡片即時展示四大維度進度，目標明確。
6. **管理威脅**：注意座標暴露和三體偏差，防止文明被降維打擊。

## 主要系統

- **熵減階段**：原子排序 → 分子冷卻 → 恒星熄滅 → 黑洞解壓 → 能量物質化 → 宇宙單一化
- **資源類型**：能量、物質、暗物質、反物質、奈米材料、量子比特、文明基因、探測器、碎片/日誌等
- **科技與建築**：每個階段有專屬科技和建築，支援熵減進程
- **宇宙探索**：高方差掉落池、稀有掉落、碎片/日誌收集與合成
- **畢業進度**：科技、階段、建築、熵減完成度四維度進度條
- **GM 面板**：開發/測試專用，支援一鍵調整所有核心資料
